# Five Nights at Bách Khoa — Survival GDD

Upload the project folder to Overleaf, set `report.tex` as the main document and select pdfLaTeX. The editable report content is `chapters/submission_gdd.tex`; `docs/GDD.md` in the repository records the design decisions. The student team should review the revised scope and course requirements before submission.

The five hand-drawn diagrams are in `diagrams/submission/`, and the mood board source is in `diagrams/survival/`. The campus overview is a local Studio capture; HUD and menu images are conceptual wireframes with editable HTML/CSS sources. Optional concept-art prompts are in `AI_IMAGE_PROMPTS.md`.
